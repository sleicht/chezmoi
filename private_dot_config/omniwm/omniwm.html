Window management

Workspaces use the Dwindle layout. Native macOS fullscreen has no assigned shortcut.

ShortcutAction
Ctrl + QClose focused window
Ctrl + FToggle OmniWM fullscreen
Ctrl + Alt + FToggle floating / tiling
Ctrl + Alt + OFlip split orientation (horizontal / vertical)
Ctrl + Alt + SpaceOpen command palette

Resize windows

Use the Equal (=) and Minus (−) keys. Add Shift for height. These are direct shortcuts; no resize mode is required.

ShortcutAction
Ctrl + Alt + =Grow width
Ctrl + Alt + −Shrink width
Ctrl + Alt + Shift + =Grow height
Ctrl + Alt + Shift + −Shrink height

Config & differences from AeroSpace

Settings live-reload. There is no reload shortcut.

The following AeroSpace shortcuts have no binding in this trial:

  • Ctrl + Enter — launch Ghostty
  • Ctrl + F11 — alternate fullscreen
  • Ctrl + 9 — alternate back-and-forth
  • Ctrl + Shift + ← / → — workspace aliases
  • Ctrl + Alt + R — resize mode
  • Ctrl + Alt + S — accordion
  • Alt + Shift + ; — service mode
  • Alt + Shift + Tab — move whole workspace to next monitor
  • Alt + Shift + C — reload config
