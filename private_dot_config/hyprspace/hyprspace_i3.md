# Hyprspace Cheatsheet — i3 Style

## Navigation (Focus)

| Shortcut | Action |
|----------|--------|
| `Alt + J` | Focus left |
| `Alt + K` | Focus down |
| `Alt + L` | Focus up |
| `Alt + ;` | Focus right |

## Move Windows

| Shortcut | Action |
|----------|--------|
| `Alt + Shift + J` | Move window left |
| `Alt + Shift + K` | Move window down |
| `Alt + Shift + L` | Move window up |
| `Alt + Shift + ;` | Move window right |

## Layout

| Shortcut | Action |
|----------|--------|
| `Alt + F` | Toggle fullscreen |
| `Alt + S` | Vertical accordion (stacking) |
| `Alt + W` | Horizontal accordion (tabbed) |
| `Alt + E` | Toggle split (tiles H/V) |
| `Alt + Shift + Space` | Toggle floating/tiling |
| `Alt + H` | Join with window below |
| `Alt + V` | Join with window left |

## Monitor

| Shortcut | Action |
|----------|--------|
| `Alt + Shift + Tab` | Move workspace to next monitor |

## Resize Mode (`Alt + R`)

| Shortcut | Action |
|----------|--------|
| `H` | Shrink width |
| `L` | Grow width |
| `J` | Grow height |
| `K` | Shrink height |
| `Enter` / `Esc` | Exit resize mode |

## Service Mode (`Alt + Shift + ;`)

| Shortcut | Action |
|----------|--------|
| `Esc` | Reload config & exit |
| `R` | Reset layout (flatten) |
| `F` | Toggle floating/tiling |
| `Backspace` | Close all windows but current |

## Config

| Shortcut | Action |
|----------|--------|
| `Alt + Shift + C` | Reload config |
