Add the following fzf-tab zstyles in a new `# === fzf-tab ===` section:

1. **General fzf-tab settings:**
   ```zsh
   # Switch fzf-tab completion to use tmux popup if available, otherwise standard
   zstyle ':fzf-tab:*' fzf-flags --color=fg:#f8f8f2,bg:#282a36,hl:#bd93f9,fg+:#f8f8f2,bg+:#44475a,hl+:#bd93f9,info:#ffb86c,prompt:#50fa7b,pointer:#ff79c6,marker:#ff79c6,spinner:#ffb86c,header:#6272a4
   # Use the same group colouring for completion groups
   zstyle ':fzf-tab:*' switch-group '<' '>'
   ```

2. **File preview (FZFT-01):**
   ```zsh
   zstyle ':fzf-tab:complete:*:*' fzf-preview 'bat --color=always --theme=Dracula --number --line-range :100 -- ${(Q)realpath} 2>/dev/null || echo ${(Q)realpath}'
   ```
   This is the default fallback preview for any completion. It tries bat first; if the item isn't a file, falls back to echoing the value. This covers FZFT-01.

3. **Directory preview (FZFT-02):**
   Use a more targeted approach. fzf-tab uses completion tags to differentiate. For directory completions:
   ```zsh
   zstyle ':fzf-tab:complete:cd:*' fzf-preview 'eza --tree --level=2 --icons --color=always -- ${(Q)realpath} 2>/dev/null'
   zstyle ':fzf-tab:complete:pushd:*' fzf-preview 'eza --tree --level=2 --icons --color=always -- ${(Q)realpath} 2>/dev/null'
   zstyle ':fzf-tab:complete:z:*' fzf-preview 'eza --tree --level=2 --icons --color=always -- ${(Q)realpath} 2>/dev/null'
   zstyle ':fzf-tab:complete:ls:*' fzf-preview 'eza --tree --level=2 --icons --color=always -- ${(Q)realpath} 2>/dev/null || bat --color=always --theme=Dracula --number --line-range :100 -- ${(Q)realpath} 2>/dev/null'
   ```

4. **Process preview for kill (FZFT-03):**
   Show process details via ps. Use `ps -p` with the PID to show full info:
   ```zsh
   zstyle ':fzf-tab:complete:kill:argument-rest' fzf-preview 'ps -p $word -o pid,ppid,user,%cpu,%mem,start,time,command 2>/dev/null'
   zstyle ':fzf-tab:complete:kill:argument-rest' fzf-flags --preview-window='bottom,40%,border-rounded,wrap'
   ```
   Use `$word` (the raw completion word which is the PID). Show pid, ppid, user, CPU%, mem%, start time, elapsed time, and command.

5. **Environment variable preview (FZFT-04):**
   Show the current value of the env var, truncated at ~200 chars:
   ```zsh
   zstyle ':fzf-tab:complete:(-command-|-parameter-|-brace-parameter-|export|unset|expand):*' fzf-preview 'echo ${(P)word} | head -c 200'
   ```

6. **Git log preview for branch completions (FZFT-05) -- per user decision: oneline format with graph:**

   The user explicitly decided: "Git log (checkout/branch): oneline format with graph (compact branch visualisation)". This overrides the FZFT-05 requirement wording ("git diff preview when completing branch names"). Using `git log --oneline --graph` per user decision.

   For `git checkout`, `git switch`, `git merge`, `git rebase`, and `git branch`:
   ```zsh
   zstyle ':fzf-tab:complete:git-(checkout|switch|merge|rebase|branch):*' fzf-preview 'git log --oneline --graph --color=always --decorate $word 2>/dev/null | head -50'
   ```

7. **Git log preview for commit hash completions (FZFT-06):**

   Cover all commands that accept commit hashes -- not just `git log`, but also `git show`, `git reset`, `git revert`, and `git cherry-pick`:
   ```zsh
   zstyle ':fzf-tab:complete:git-(log|show|reset|revert|cherry-pick):*' fzf-preview 'git log --oneline --graph --color=always --decorate $word 2>/dev/null | head -50'
   ```

8. **Git add/stage preview (git diff for staging context):**
   For `git add` completions, show the diff of the file being added. Format is Claude's discretion per CONTEXT.md -- full diff is most useful for individual files in a 40% bottom pane:
   ```zsh
   zstyle ':fzf-tab:complete:git-(add|stage|diff|restore):*' fzf-preview 'git diff --color=always -- $word 2>/dev/null | head -100'
   ```

9. **Preview window defaults for fzf-tab:**
   ```zsh

   ```

Ensure all `2>/dev/null` redirects are in place so failed previews (e.g., nonexistent files) don't show error messages.
